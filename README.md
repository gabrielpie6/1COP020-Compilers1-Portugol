# UEL - 1COP020 - Trabalho T1: Portugol

A aplicação portugol é um compilador descendente recursivo baseado em gramática LL(1) para um subconjunto da pseudolinguagem Portugol.

---

No diretório inputs são encontrados códigos utilizados como arquivos de entrada para a aplicação. Respectivamente, em outputs são encontradas as saídas esperadas para cada dado input.
